# Home Network Design & Administration

## Overview

This project documents the design, installation, and ongoing administration of my home network. I built this environment to strengthen my hands-on IT infrastructure, networking, and troubleshooting skills while creating a scalable, enterprise-inspired network for my home.

---

## Hardware

| Device | Model |
|---------|-------|
| Router | Netgear Nighthawk RAX54 |
| Primary Switch | HPE OfficeConnect 1620 (24-Port) |
| Secondary Switch | Cisco SG110-16 |
| DNS Filtering | Raspberry Pi running Pi-hole |
| UPS | APC Battery Backup |
| Cabling | Cat6A Structured Cabling |

---

## Features

- ISP modem configured in Bridge Mode
- Structured Cat6A cabling throughout the home
- Centralized patch panel
- Static IP assignments for infrastructure devices
- Separate 5 GHz, 2.4 GHz, and Guest wireless networks
- QR-code guest Wi-Fi onboarding
- Raspberry Pi Pi-hole DNS filtering
- Custom-built Windows desktop
- Ongoing network monitoring and maintenance
